# 🤖 Telegram Bot для анализа чатов VK MAX

Telegram бот для интеграции с системой анализа чатов VK MAX, который позволяет управлять чатами, загружать сообщения и публиковать результаты анализа.

## 🚀 Возможности

- 📊 Управление чатами VK MAX через Telegram интерфейс
- 🔄 Загрузка и анализ сообщений с сохранением в SQLite
- 📈 Публикация результатов анализа в группы
- 🔄 Обновление существующих сообщений в группах
- 📋 Статистика по чатам и дням

## 📦 Установка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
GIGACHAT_API_KEY=your_gigachat_api_key
VK_MAX_TOKEN=your_vk_max_token
```

### 3. Получение токенов

#### Telegram Bot Token
1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен и добавьте в `.env`

#### GigaChat API Key
1. Зарегистрируйтесь на [GigaChat](https://developers.sber.ru/portal/products/gigachat)
2. Получите API ключ и добавьте в `.env`

#### VK MAX Token
1. Получите токен VK MAX (используйте существующий `login_token.txt`)
2. Добавьте в `.env`

## 🚀 Запуск

```bash
python -m telegram_bot.bot
```

## 📱 Использование

### 1. Добавление бота в группу
1. Добавьте бота в Telegram группу
2. Сделайте бота администратором
3. Отправьте `/start` в группе

### 2. Управление чатами
1. Отправьте `/start` в личных сообщениях
2. Выберите группу для работы
3. Используйте меню "📊 Управление чатами"

### 3. Добавление чата VK MAX
1. Нажмите "➕ Добавить чат"
2. Введите ID чата VK MAX
3. Бот проверит доступ и добавит чат

### 4. Загрузка сообщений
1. Выберите чат из списка
2. Нажмите "🔄 Загрузить сообщения"
3. Бот загрузит и сохранит сообщения в БД

### 5. Анализ и публикация
1. Нажмите "📋 Проверить суммаризацию"
2. Выберите дату для анализа
3. Бот создаст суммаризацию с помощью GigaChat
4. Нажмите "📤 Вывести в группу" для публикации

## 🗄️ База данных

Бот использует SQLite для хранения данных:

- **users** - пользователи бота
- **groups** - Telegram группы
- **vk_chats** - чаты VK MAX
- **messages** - сообщения по дням
- **summaries** - суммаризации
- **group_messages** - сообщения бота в группах

## 🔧 Конфигурация

Настройки в `config.py`:

```python
TELEGRAM_BOT_TOKEN = "your_bot_token"
GIGACHAT_API_KEY = "your_gigachat_key"
VK_MAX_TOKEN = "your_vk_max_token"
DATABASE_PATH = "bot_database.db"
CHATS_DIR = "../chats"
MAX_MESSAGE_LENGTH = 4096
```

## 📊 Состояния бота (FSM)

- `START` - начальное состояние
- `SELECT_GROUP` - выбор группы
- `MANAGE_CHATS` - управление чатами
- `ADD_CHAT` - добавление чата
- `CHAT_SETTINGS` - настройки чата
- `LOADING_MESSAGES` - загрузка сообщений
- `VIEW_SUMMARY` - просмотр суммаризации
- `PUBLISH_SUMMARY` - публикация в группу

## 🛠️ Разработка

### Структура модулей

#### `bot.py` - Основной файл
- Инициализация бота и БД
- Регистрация обработчиков команд
- Настройка FSM состояний
- Запуск polling

#### `database.py` - Работа с БД
- `init_database()` - создание таблиц
- `get_user_groups()` - группы пользователя
- `add_vk_chat()` - добавление чата
- `save_messages()` - сохранение сообщений
- `get_chat_stats()` - статистика чата

#### `vk_integration.py` - VK MAX API
- `load_chat_messages()` - загрузка сообщений
- `get_chat_info()` - информация о чате
- `check_chat_access()` - проверка доступа
- `save_messages_to_db()` - сохранение в БД

#### `chat_analyzer.py` - Анализ чатов
- `get_gigachat_token()` - получение токена
- `call_gigachat_api()` - анализ чата
- `optimize_text()` - оптимизация текста
- `analyze_chat_by_date()` - анализ за день
