# Анализатор чатов с GigaChat

Скрипт для анализа сохраненных чатов с помощью GigaChat API.

## Возможности

- ✅ Выбор чата из сохраненных файлов
- ✅ Выбор даты для анализа
- ✅ Оптимизация текста для экономии токенов
- ✅ Интеграция с GigaChat API
- ✅ Структурированное резюме по темам и проблемам
- ✅ Сохранение результатов в файл

## Установка

```bash
pip install requests
```

## Настройка

1. Получите API ключ от GigaChat
2. Установите переменную окружения:
```bash
export GIGACHAT_API_KEY="ваш_api_ключ"
```

## Использование

```bash
python analyze_chat.py
```

## Пример работы

1. Выберите чат из списка
2. Выберите дату для анализа
3. Получите структурированное резюме:
   - Основные темы
   - Проблемы и вопросы
   - Решения и действия
   - Важные моменты

## Особенности

- Автоматическая оптимизация текста (убирает лишние символы, сокращает длинные сообщения)
- Ограничение длины до 8000 символов для экономии токенов
- Тестовый режим без API ключа для демонстрации функционала
- Сохранение результатов в файл `{дата}_summary.txt`
