   ```env

   GIGACHAT_API_KEY=your_gigachat_api_key
   VK_MAX_TOKEN=your_vk_max_token
   ```

2. **Установка зависимостей**:
   ```bash
   pip install -r telegram_bot/requirements.txt
   ```

3. **Запуск бота**:
   ```bash
   cd telegram_bot
   python run_bot.py
   ```
