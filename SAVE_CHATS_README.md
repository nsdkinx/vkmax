# Скрипт сохранения сообщений чатов

Простой скрипт для сохранения сообщений VK MAX чатов по дням с инкрементальным обновлением.

## Использование

### 1. С параметром chat_id (автоматический выбор чата):
```bash
python save_chats.py 12345
```

### 2. Интерактивный выбор чата:
```bash
python save_chats.py
```

## Функционал

- **Автоматическое создание структуры**: `chats/{chat_id}/YYYY-MM-DD.json`
- **Инкрементальное обновление**: загружает только новые сообщения
- **Сохранение по дням**: каждый день в отдельном файле
- **Глубина 7 дней**: автоматически обрабатывает последнюю неделю
- **Защита от дубликатов**: не загружает уже сохраненные сообщения

## Структура файлов

```
chats/
├── 12345/           # ID чата
│   ├── 2024-01-15.json
│   ├── 2024-01-16.json
│   └── 2024-01-17.json
└── 67890/           # Другой чат
    ├── 2024-01-15.json
    └── 2024-01-16.json
```

## Формат файлов

Каждый JSON файл содержит массив сообщений:
```json
[
  {
    "id": "123456789",
    "text": "Текст сообщения",
    "sender": "user_id",
    "time": 1705123456789,
    "type": "TEXT"
  }
]
```

## Требования

- Файл `login_token.txt` с токеном авторизации
- Python 3.7+
- Установленные зависимости из `requirements.txt`

## Особенности

- При повторном запуске загружает только новые сообщения
- Автоматически определяет последний сохраненный ID сообщения
- Обрабатывает дубликаты при пагинации
- Минимальный код - только необходимый функционал
